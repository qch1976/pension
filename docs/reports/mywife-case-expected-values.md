### 2.2 语义模糊点 / 提示项（非阻断，测试须知）

1. **【需用户裁决，最重要】应缴窗口起点**：任务书口径=2003-09；引擎口径=**1992-10 硬编码**（`insuredWindowStart` 仅对 `doc31Eligible=true` 且有 `enterpriseInsuredYM` 的31号文人员改用参保月，普通人员一律 1992-10）。后果：MY3 分母 465 而非 334、MY4 525 而非 394。spec §2.1（N应缴"自1992-10起…含未实际缴费的间断月"）支持引擎现行行为，但"未在业期间是否算应缴"官方无逐条问答（与 T-05 同源争议）。**本轮标注为语义分歧/潜在口径缺陷，不修。**
2. **【2003 起始月】** 年度行默认 startMonth=1，若直接录 4 个月会排成 2003-01~04；参工实为09月，逐月明细语义错误。**录入时必须把 2003 行起始月改为 9**。年值法 Z年/Σ月z 不受排月位置影响（窗口内同月置换），故金额不变，但逐月断言须用 9~12 月。
3. **【断缴月位置未指定】** 2005 缺5月、2006 缺3月，案例只给年基数+月数；按连排处理时缺口落在年末。北京口径只要求"窗口内断缴月 z=0、计入 K"，缺口具体月份不影响 Z年/Z实（年值法）；若测试要逐月断言，须先与用户约定缺口排法（建议连排1月起）。
4. **【P05 弹性范围 warning】**
   - 女工人 1981-07 出生：P05 法定退休月 = **2034-11**（延迟40月）。MY3 选 2031-07 = 原法定年龄，但比弹性窗口下限（max(原法定2031-07, 法定−36月=2031-11) = **2031-11**）还早4个月 → index 页 `retireHint` 会提示"**超出弹性范围，请核对**"；引擎给"相差 -40 个月"warning。均**不阻断**（用户自选退休月设计）。若严格按 P05，50岁整退对该出生月可能不被允许，提请用户知晓。
   - MY4 选 2036-07 = 法定 +20 月，在 +3 年弹性内 ✓（仍有"与法定相差20月"常规提示）。
5. **【分母缺口 warning ×4】** 因窗口自1992-10起，1992/1993/1994/1995 无官方分母键（T-10），引擎各发一条"缺少官方月平均工资"warning；这些年无缴费、z=0，无数值影响。口径B（窗口2003起）下不会出现这4条。
6. **【C平 年度不一致 warning】** 缺省用 2025 年计发基数 12049，两案退休年均在未来，必有"C平暂按2025年度12049元计发"warning；断言以 12049 为准。
7. **首账号字段无独立录入位**：首账号=参工月=2003-09，输入页不单独采集；引擎也不使用"首账号"概念（物理建账截断恒为1992-10）。本案两者同月无矛盾，仅说明。
8. **R补 规则确认**：`doc31Eligible=false` → `accountSubsidy` 直接返回 `not-doc31-person`，**R补=0、applicable=false**，J账户=R储/M。本案非机关事业转入、非军转，完全符合 AC-RC-02。不得把其他补贴计入。

**未发现会导致 throw 或算错的引擎硬缺陷**；上述 #1 为口径分歧（按 spec 现行文本引擎"正确"，但与任务书预期冲突），#2~#6 为录入/提示层面的语义注意点。
