## 2. 核实的官方口径（与 spec V1.1 逐条比对）

1. **施行时间**：决定 2024-09-13 第十四届全国人大常委会第十一次会议通过，**自 2025-01-01 起施行**（与 spec 一致）。
2. **办法第一条（延迟节奏，决定附件1-3对照表口径）**：
   - 男职工：原法定退休年龄 60 周岁，**1965年1月至1976年12月出生的，每4个月延迟1个月**，1976年9月及以后出生的按63周岁退休；
   - 原55周岁女职工（管理技术岗/女干部）：**1970年1月至1981年12月出生的，每4个月延迟1个月**，1981年9月及以后按58周岁退休；
   - 原50周岁女职工（女工人）：**1975年1月至1984年12月出生的，每2个月延迟1个月**，1984年11月及以后按55周岁退休。
3. **首行锚点（新华社对照表逐行视觉抽核 + 条文数学推导双重验证）**：
   - 男 1965-01 → 退休 2025-02（60岁1月）；
   - 女干部 1970-01 → 2025-02（55岁1月）；
   - 女工人 1975-01 → 2025-02（50岁1月）。
   - 男表抽核：1965-01→2025-02（延1月）、1965-05→2025-07（延2月）、1976-09→2039-09（63岁，延36月封顶）；
   - 女工人表抽核：1975-03→2025-05（延2月，每2个出生月延1月）、1984-11→2039-11（55岁，延60月封顶）。
4. **办法第二条 + 附件4《提高最低缴费年限情况表》**：从 2030年1月1日起，职工按月领取基本养老金最低缴费年限由15年逐步提高到20年，**每年提高6个月**；2025-2029年仍为15年。视觉核实附件4：2030=15年6个月（186月）、2035=18年（216月）、2039=20年（240月）。
5. **办法第三条（弹性）**：达到最低缴费年限可自愿弹性提前/延迟，**各不超过3年；提前退休不得低于原法定退休年龄**；企业职工需与单位协商一致。计算引擎只做年龄/年限数学判定，协商等经办要件在 UI 提示中说明。

## 3. 代码落地方式（规则化而非抄全表）

- 新增 `calculator/retireSchedule.js`：按"受影响出生起点 + 每 N 个出生月延 1 月 + 封顶月数"规则逐月推算，与官方对照表数学等价；锚点以官方对照表抽核验证（见 `tests/round1-fixes.js` GAP-01-M1~W2）。规则与锚点在文件头注释标注来源。
- `constants/policyData.js` 增 `delayRetire` 配置与 `minContributionMonthsByYear` 年表（附件4），引擎 `minRequiredMonths()` 按退休年份查取；资格判定随之动态化。
- 输入页按出生年月自动给出法定退休年月并提示延迟月数与弹性区间；结果页新增"法定退休年龄对照（P-05）"卡，展示对照表法定退休年月、本次选择偏移、弹性区间。
- 计发月数 M 按**本次实际退休年龄（满整岁，spec T-14）**取国发〔2005〕38号附表（如 58 岁 M=152）。
