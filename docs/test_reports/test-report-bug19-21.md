## 过程技术说明（如实）

- 断言以 page.data()+真实 DOM 为权威。证据截图阶段，automator 对 scroll-view 的多次复合操作存在 webview meta 瞬态丢失（getPageMetaByWebviewId null）及整屏 screenshot 偶发超时；最终采用"每张证据独立 fresh cli auto、逻辑层 createSelectorQuery 实测坐标定位、到达即截"获得稳定真实证据。
- scroll-view 内部滚动定位须以实测 scrollHeight − 容器高 计算末行位置；对离屏 scroll-view 的内部滚动会被丢弃，须先将卡片滚入视口；其后任何 pageScrollTo 会重置内部 scrollTop，故年表末行截图不再做二次页面滚动（脚注本就与年表卡在同一视口）。
- 环境全程就绪（session 2 活动、60964 Listen），未发生 environment-session defect，无谎报。
