## 2. 基准建模（与 ROI 对齐的唯一口径）

停保基准**必须复用** ROI 的逐方案 0 投入基线：`roiModel.buildCaseInput(sharedInput, plan, false)`
（仅保留历史段、不追加自动段、`futureMonthlyRate=null`、`retireYM` 取该方案自身值）。

- ROI 基线：`P月_k^停保 = baselineResult.pension.total`（`computeROI` 已产出 `baselineMonthly`）。
- 新回本行基准月养老金 = **同一个** `P月_k^停保`；停保月负担恒 0。
- **禁止**另行构造停保输入或复制一套现金流逻辑。

## 3. 计算口径（沿用 spec §9.3 三分支，仅换基准）

因停保基准月负担恒 0 且 T_b = T_k（同退休月）：

```
ΔP_k = P月_k^继续 − P月_k^停保
FV_k = Σ_{m=0..T_k} (B_m^k × rate_k) × (1+i)^(T_k−m)      // i = r/12
r = 0  : n = FV_k / ΔP_k
r > 0  : n = −ln(1 − FV_k·i/ΔP_k) / ln(1+i)
展示：向上取整到整月；ΔP_k ≤ 0 或年金现值不足 → 「该利率下无法抵回」
```
