# 北京市企业职工养老金测算小程序

依据北京市企业职工基本养老保险官方政策，计算退休人员首月基本养老金，包含**基础养老金 J基础、个人账户养老金 J账户、过渡性养老金 J过渡（G同+G实）**三个分项与总额，并展示 C平、Z实指数、Z同指数、N应缴、K应缴、N实+同、N同、N实98、R储（本金/利息分列）、M、G同、G实等全部中间变量（**精确到月**）。

- 适用范围：**企业职工基本养老保险**（非城乡居民养老保险）；支持 1992-10 前参加工作的"中人"（含视同缴费年限、G同、G实、1998-06 前实缴指数）。
- 适用人群：单位参保职工、失业后转灵活就业人员（20% 缴费、8% 入账，成本单列不进计发公式）。
- 数据来源：官方政策参数集中在 `constants/policyData.js`（含版本号，年度更新只改配置），政策引用集中在 `constants/policyRefs.js`，计算引擎与页面解耦，可直接在 node 下自测。

> 测算结果仅供参考，以北京市社保经办机构核定为准。

## 已实现清单

- [x] 三分项计算与总额：J基础、J账户、J过渡（G同+G实），**总额恒等于三个分项展示值之和**（BUG-013 修复）
- [x] 官方公式：Z实指数 = Σ(X年/C年) ÷ N应缴；Z同指数=1.0；N应缴含断缴月（断缴月指数计0仍计分母，T-05）
- [x] 精确到月：K应缴、N同、N实98、N实+同、视同年限、退休当月不缴费、跨年段分母自动切换
- [x] **渐进式延迟法定退休年龄逐月对照表（P-05，2025-01-01施行）**：男/原55岁女职工每4个月延1个月、原50岁女职工每2个月延1个月；按出生年月自动给出法定退休年月（手工可改），展示弹性提前/延迟±3年区间（提前不低于原法定年龄）；M 按实际退休年龄取表
- [x] **最低缴费年限动态表（P-05附件4）**：2025-2029=15年，2030=15年6个月起每年+6个月，2039年起=20年；资格按退休年度判定
- [x] 中人/新人判定（1998-07 分界）、视同缴费年限（按参加工作时间估算/手工认定两种模式）、视同月数与工龄矛盾截断（E-08）
- [x] 个人账户：8% 入账（灵活就业同口径）、**月入账精确值全程不舍入**（spec 4.7）、本金/利息分列
- [x] 三种利息模式：官方历年记账利率（缺失年度预估利率并标【待官方核实】）/ 固定年利率（0~24% 校验）/ 不计息；当年缴费"次月起按月折算/半年简化"两种口径，**半年口径退休当年缴费仍按月折算**（spec 4.6）
- [x] 灵活就业段：20% 缴费成本提示（不进计发公式）、缴费基数 60%-300% 核定区间越界黄字提示（E-05）
- [x] C平 年度选择与手工覆盖；1991-1994 缺口年度 C年手工录入（按 C 年度口径，兼容旧按缴费年度口径）
- [x] 录入：分段月度模式 + **年度模式（月均基数+当年缴费月数1~12，FR-05）**；复制上一段（FR-04）、全口径60%/100%/300%快捷填充
- [x] 完整输入校验：出生年月范围、退休年龄40-70、退休不早于参加工作、视同月数0~600整数、利率/C平/账户额非负（硬错误阻断）
- [x] 软问题黄字提示：重叠段后段覆盖、缴费早于1992-10（E-02）、晚于退休前一月截断（E-03）、缺口年度、年度口径沿用、延退选择与法定不一致等
- [x] 结果页：资格条、延退对照卡、总额三分项、全部中间变量（X年Y月展示）、**按年记账表（当年利息/年末余额/利率来源角标）**、逐月明细按年折叠（含当年利息与年末余额）、公式政策标签弹窗（FR-12，ref 键统一 P01~P12）
- [x] **R补=官方「个人账户补贴额」Z补贴（spec V1.2 §2.2.1，京劳社养发〔2007〕31号第二条(三)+附件1）**：仅1998-01后机关事业转企业/调入/军转三类人员；分档模拟额（2%/5%/11%/8%）×参保后Z实指数；J账户=(R储+R补)÷M；Z补贴 不计入账户实际储存额；普通职工 R补=0、总额与V1.1零差异（AC-RC-02）；支持已享27号文/后联字3号一次性补贴年限按月扣除（AC-RC-08）
- [x] 符号映射（AC-RC-01）：R储=21号文「个人账户累计储存额」、R补=31号文「个人账户补贴额 Z补贴」，均为用户口径符号（非官方字母符号），代码注释与页面文案双向标注
- [x] 逐月明细 **CSV 导出**（复制剪贴板，可粘贴 Excel/微信，FR-11）；分享给朋友
- [x] 免责声明、不采集姓名/身份证声明；数据仅存本地 storage
- [x] 政策可维护：官方数据全部抽离 JSON 风格配置（NFR-02）；三级来源角标贯穿 UI（官方/工程假设/待确认，NFR-04）
- [x] 自测：全量 135 条 + R补专项 46 条 + 首轮修复专项 33 条 + 回归 50 条 + 视图模型审计 + WXML 静态检查，均 node 可运行

## 政策参数更新

每年北京市公布新计发基数/全口径工资、人社部公布记账利率后：更新 `constants/policyData.js` 中对应年度数值与 `version`；P-05 对照表为规则化实现（`calculator/retireSchedule.js`），无需逐年维护。
